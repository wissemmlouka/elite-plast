# Component Patterns

## Objective

Every section must follow a consistent visual language.

The website should feel like one coherent product, not a collection of independent sections.

Reuse existing components whenever possible.

Never create a new section if an existing pattern can be adapted.

---

# General Rules

Every section should contain:

- Section label (optional)
- Heading
- Supporting paragraph
- Main content
- Call-to-action (when appropriate)

Maintain the same spacing across all pages.

Desktop

120px vertical spacing

Tablet

96px

Mobile

72px

---

Structure

Secondary CTA

Hero image or illustration

12 words

Maximum description:

40 words

Multiple columns

Tablet

44px

---

# Reusability

Before creating a component ask

Can an existing component solve this?

If yes

Reuse it.

Do not duplicate components.

---

# Quality Checklist

Before considering a section complete verify

✓ Consistent spacing

✓ Responsive

✓ Accessible

✓ Reusable

✓ SEO friendly

✓ Performance optimized

✓ Minimal

✓ Professional

✓ Matches brand identity

✓ Includes appropriate CTA

Every component should feel like it belongs to the same design system.
