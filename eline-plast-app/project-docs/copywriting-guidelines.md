# Copywriting Guidelines

## Objective

Write clear, persuasive, and professional copy that builds trust, improves SEO, and encourages visitors to take action.

The tone should reflect a premium, reliable company with technical expertise.

---

# Brand Voice

Professional

Trustworthy

Modern

Confident

Helpful

Human

Avoid sounding corporate or robotic.

---

# Writing Style

Use simple language.

Be concise.

Write for humans first.

SEO second.

Every sentence should have a purpose.

Avoid filler.

---

# Tone

Confident

Positive

Honest

Technical when necessary

Friendly

Never exaggerate.

Never make unverifiable claims.

---

# Headlines

Headlines should

Be short

Communicate value

Create curiosity

Examples

Reliable Irrigation Solutions

Smart Water Management

Professional Irrigation Systems

Premium PVC Products

Avoid generic titles like

Welcome

Our Website

Home

---

# Paragraphs

Maximum

3–4 sentences

Break long content into sections.

Use bullet points whenever possible.

---

# Calls To Action

CTAs should use action verbs.

Examples

Request a Quote

Contact Our Team

Explore Our Products

Talk to an Expert

Get Started

Learn More

Avoid

Click Here

Submit

Read More

---

# SEO

Naturally include target keywords.

Do not keyword stuff.

Use

H1

H2

H3

Meta descriptions

Image alt text

Internal links

Every page should target one primary keyword.

---

# Reading Level

Write so that anyone can understand the content.

Avoid unnecessary technical jargon.

Explain technical terms when needed.

---

# Trust Elements

Highlight

Experience

Quality

Customer satisfaction

Reliable service

Professional support

Industry expertise

Use numbers when available.

Example

20+ Years of Experience

500+ Projects

1000+ Happy Customers

Never invent statistics.

---

# Product Descriptions

Focus on benefits before features.

Instead of

PVC Pipe

Write

Durable PVC pipes designed for long-lasting irrigation performance.

---

# Service Descriptions

Explain

Problem

Solution

Benefit

Call to Action

---

# About Page

Tell the story.

Explain

Mission

Values

Experience

Commitment

Keep it authentic.

---

# FAQ

Provide direct answers.

Use conversational language.

Answer real customer questions.

---

# Contact Page

Make it easy to contact the company.

Encourage visitors to reach out.

Reduce friction.

---

# Error Messages

Friendly

Helpful

Specific

Example

Please enter a valid email address.

Avoid

Invalid Input.

---

# Success Messages

Positive

Clear

Example

Thank you. Your message has been sent successfully.

---

# Microcopy

Buttons

Menus

Forms

Labels

Tooltips

Should all be concise.

---

# Language Rules

Prefer active voice.

Examples

We install irrigation systems.

Instead of

Irrigation systems are installed by us.

---

# Consistency

Always use the same terminology.

Never alternate between different names for the same product or service.

---

# AI Writing Rules

Never generate fake testimonials.

Never invent awards.

Never invent certifications.

Never fabricate project data.

Clearly identify placeholder content when real information is unavailable.

---

# Final Checklist

Before writing, verify

✓ Clear

✓ Helpful

✓ Human

✓ SEO-friendly

✓ Easy to scan

✓ Action-oriented

✓ Brand-consistent

✓ Grammatically correct

✓ No repetition

✓ No unnecessary words
