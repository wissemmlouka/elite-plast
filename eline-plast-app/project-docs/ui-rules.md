# UI Rules

## Objective

Build a premium, modern, and trustworthy website.

The design quality should be comparable to:

- Apple
- Stripe
- Linear
- Vercel
- Framer
- Notion

The interface should feel clean, elegant, lightweight, and professional.

Never sacrifice usability for visual effects.

---

# Design Principles

- Simplicity first.
- Every element must have a purpose.
- Prefer whitespace over visual clutter.
- Design for clarity before aesthetics.
- Consistency is mandatory.
- Follow an 8px spacing system.
- Mobile-first design.
- Accessibility by default.

---

# Shadows

Use soft shadows only.

Cards

Light shadow

Hover

Slightly larger shadow

Never use heavy shadows.

---

# Colors

Use the brand colors.

Primary

Blue

Secondary

Green

Neutral

White

Light Gray

Dark Gray

Text

Dark Navy

Never introduce additional accent colors without approval.

---

# Typography

Headings

Bold

High contrast

Body

Comfortable reading

1.6 line height

Maximum paragraph width

70 characters

Avoid long text blocks.

---

# Buttons

Always provide:

Primary Button

Secondary Button

Ghost Button

Buttons should include:

Hover

Focus

Disabled

Loading

States must be visually distinct.

---

# Cards

Cards should have

Rounded corners

Soft shadow

Consistent padding

Hover feedback

Never overload cards with information.

---

# Icons

Use one icon style throughout the website.

Preferred

Simple outline icons

Consistent stroke width

Never mix icon packs.

Modern
